# 群回答与新人欢迎运行时补丁

本目录保存项目自研的、可审阅的消息展示和新人欢迎逻辑，不包含第三方内核、解包产物、活动群 ID、成员 ID、欢迎文案或运行状态。

功能包括：

- 清理触发词并生成“原问题 + 分隔线 + 完整回答”的群消息正文；
- 继续使用第三方内核发送接口的真实 `at_list`，不伪造文本艾特；
- 使用 `ContextVar` 隔离并发群问题，私聊保持原样；
- 只在 SHA-256 白名单群处理成员新增事件；
- 排除邀请人、艾特全部新增成员，并通过事件 hash 抑制重复发送；
- 状态文件仅保存事件 hash 和时间戳，使用临时文件加原子替换写入。

## 测试

在仓库根目录执行：

```powershell
python -m unittest discover -s onboarding -p 'test_*.py' -v
```

当前测试使用完全虚构的群、成员和知识来源。

## 本地配置

复制 `config.example.json` 为 `config.json`，再在隔离测试机填写本地值。`config.json` 已被 Git 忽略，不得提交真实群 hash、公司文案或内部链接。

## 运行边界

`newqi24_onboarding_launcher.py` 是针对已审阅第三方 PyInstaller 内核的实验性加载器。它要求本机已有与固定样本匹配的解包运行组件；本仓库不提供这些组件，也不保证对其他企业微信或内核版本兼容。

这不是企业微信官方插件。只能在专用测试账号、测试群、虚构数据和可回滚环境中使用。
